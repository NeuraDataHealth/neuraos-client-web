# NeuraOS client

Medical AI chat for Indian healthcare professionals. Next.js App Router, Firebase, Gemini on Vertex AI.

## Setup

```bash
bun install
cp .env.example .env.local
# fill in the values in .env.local (ask Dhruti)
bun run dev
```

Read `AGENTS.md` before you start, then pick your next task from `docs/TASKS.md`. The spec is `docs/SPEC.md`.
